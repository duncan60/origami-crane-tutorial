# 摺紙教學 · 3D 互動原型

用 3D 摺疊動畫逐步教人摺紙。每一步都可以自由旋轉視角、拖曳進度條停在摺到一半的任何瞬間觀察紙層關係，並可切換作品與紙張顏色。

**線上版本**：https://duncan60.github.io/origami-crane-tutorial/

| 作品 | 難度 | 步驟 | 最厚層數 |
| --- | --- | --- | --- |
| 狗臉 | 入門 | 3 | 11 |
| 紙飛機 | 初級 | 5 | 15 |
| 武士帽 | 中級 | 6 | 15 |

摺法定義各在 `src/dog.ts`、`src/plane.ts`、`src/kabuto.ts`，註冊表在 [src/models.ts](src/models.ts)——新增作品只要寫一個 StepDef 陣列加一行註冊。網址 hash 記住目前作品（`#dog` / `#plane` / `#kabuto`），紙色存在 localStorage。

武士帽傳統摺法的最後一步是「塞進帽子內側」，塞入口袋不是鏡射能表達的動作，採用常見的簡化版（往後翻摺）。

這是一個**技術驗證原型**，要驗證的假設是：「3D 摺疊動畫 + 自由旋轉視角 + 進度拖桿，能讓使用者看懂並跟著摺出來。」

## 為什麼沒有紙鶴

最初做的是紙鶴（見 git 歷史，`src/crane.ts`）。幾何全部正確——12 個步驟都通過面積守恆與摺平精度驗證——但**教不會人**，原因值得記下來：

摺紙教學真正要傳達的資訊是「現在要抓哪一層紙」。紙鶴摺到後半段有 **23～40 層紙**疊在一起，在 3D 裡從上方看下去每一層都是同色平面、外觀完全一樣，使用者看得到形狀變化卻看不出動的是哪一層。而且花瓣摺、內翻摺都需要「撐開紙層」——這是把每一摺當成鏡射的模型本質上表達不出來的操作。

**這是資訊呈現的問題，不是渲染問題。** 一開始誤判成渲染問題，於是反覆調紙厚與 z-fighting，都沒碰到痛點。

現有三個作品都落在這個引擎能精確表達的範圍內：**全部都是單純對摺**（沒有花瓣摺、沒有內翻摺、不需要撐開口袋），層數低到紙層結構一眼可辨。正反雙色讓摺角與底紙自然區分。

## 摺紙引擎怎麼運作

核心在 [src/fold.ts](src/fold.ts)。

紙張以「攤平座標系」中的多邊形集合表示。每一摺都是**把選定的面沿一條摺線做鏡射**——這是摺平狀態的精確模型；3D 顯示時則把同一個鏡射換成**繞摺線旋轉 0→180 度**，所以動畫全程每個面都保持剛體，紙不會像果凍一樣被拉伸。

支撐整套機制的不變量是：**在完全摺平的狀態下，一個面的 3D 位置等於它攤平座標的直接嵌入**（攤平 `(x, y)` → 世界 `(x, 0, -y)`）。因為鏡射軸在自己的旋轉下不動，摺線的 3D 旋轉軸可以從任一片移動面的變換矩陣推得，即使那一摺是接在同一步驟前一個子摺之後發生的。

摺法定義（`src/dog.ts`、`src/plane.ts`、`src/kabuto.ts`）的摺線都用**當下攤平狀態的座標**指定——和真實摺紙圖解的讀法一致。

### 紙張厚度與破圖

重疊的紙層必須錯開一點才不會互相 z-fighting。這件小事踩過四個坑，最後的結論很簡單：**偏移量 = 紙厚 × √層序**。

`層序`是引擎維護的權威堆疊順序，而且同層號的面保證互不重疊（`__selftest()` 會驗這一點）。所以「重疊 ⇒ 層號不同 ⇒ 偏移量不同」，遮蔽順序必定正確，也不可能 z-fighting。平方根則負責壓縮：第 1 層分開 1 個紙厚，第 15 層只到 3.9 個紙厚，最上層不會浮離。

走到這個結論之前試過的三種做法都失敗，記下來免得再犯：

| 做法 | 失敗原因 |
| --- | --- |
| 偏移量 = 紙厚 × 層序（線性） | 層數多時最上層被推離太遠，整片穿過其他紙面 |
| 局部厚度 = 數有幾個層號較低的面蓋住自己的重心 | 兩個重疊的面用不同取樣點，數出來可能相同（z-fighting）或順序反轉 |
| 局部厚度 = 重疊關係上的最長鏈 | 鏈會在重疊圖上遊走，算出的層數遠大於該處實際層數，該部位浮離 |

正確的局部層序是已知的困難問題，原型不需要解它——單調壓縮權威層序就足夠了。

還有一個獨立的坑：**厚度變化要跟著造成它的那一摺**。複合摺的子摺各有時間區間，若用整個步驟的進度統一內插，先落下的紙層偏移量還沒到位，就會穿進下方的紙裡。

### 展開角度要接近 90°

機翼若不是接近 90° 展開，兩片會一上一下呈不對稱角度；相機仰角一旦接近其中一片的平面，那片就被壓成一條線，看起來像有東西穿過作品。接近 90° 時兩片對稱，任何仰角都不會有一片被壓扁。

### 主控台診斷

```js
__selftest()  // 一次跑完所有幾何不變量：面積守恆、摺平、同層不重疊、厚度合理
__dump(2)     // 第 3 步結束時各層的攤平多邊形
__probe(2, 1) // 該時刻是否確實攤平（摺平狀態下 y 應全為 0）
```
