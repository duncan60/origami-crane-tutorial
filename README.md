# 紙鶴摺紙教學 · 3D 互動原型

用 3D 摺疊動畫逐步教人摺紙鶴。每一步都可以自由旋轉視角、拖曳進度條停在摺到一半的任何瞬間觀察紙層關係。

**線上版本**：https://duncan60.github.io/origami-crane-tutorial/

這是一個**技術驗證原型**，要驗證的假設是：「3D 摺疊動畫 + 自由旋轉視角 + 進度拖桿，能讓使用者看懂並跟著摺出紙鶴。」

## 開發

```bash
npm install
npm run dev
```

## 摺紙引擎怎麼運作

核心在 [src/fold.ts](src/fold.ts)。

紙張以「攤平座標系」中的多邊形集合表示。每一摺都是**把選定的面沿一條摺線做鏡射**——這是摺平狀態的精確模型；3D 顯示時則把同一個鏡射換成**繞摺線旋轉 0→180 度**，所以動畫全程每個面都保持剛體，紙不會像果凍一樣被拉伸。

支撐整套機制的不變量是：**在完全摺平的狀態下，一個面的 3D 位置等於它攤平座標的直接嵌入**（攤平 `(x, y)` → 世界 `(x, 0, -y)`）。因為鏡射軸在自己的旋轉下不動，摺線的 3D 旋轉軸可以從任一片移動面的變換矩陣推得，即使那一摺是接在同一步驟前一個子摺之後發生的。這讓複合摺（花瓣摺、內翻摺）可以拆成幾個有時間區間的子摺，接續播放而不必特別處理。

摺法定義在 [src/crane.ts](src/crane.ts)，摺線都用**當下攤平狀態的座標**指定——和真實摺紙圖解的讀法一致。要摺哪幾層則用 `layers` 指定，可以用層號（`{ top: 2 }`）或更穩健的「蓋住某個位置的紙層」（`{ at, pick }`）。

### 紙張厚度與破圖

重疊的紙層必須錯開一點才不會互相 z-fighting。偏移量的計算踩過三個坑，每一個都會造成不同型態的破圖：

**一、不能用全域層號。** 紙鶴最後有 30 幾個全域層號，用層號會把頸子推離身體平面 0.17 個單位——模型本身才 1.4 大——整片穿過翅膀。要用的是「局部厚度」，也就是它在自己那一疊紙裡的高度。

**二、局部厚度不能用取樣法估。** 一度用「數有幾個層號較低的面蓋住自己的重心」，結果兩個重疊的面各自用不同取樣點，數出來可能相同 → 偏移量一樣 → 斑駁鋸齒狀的 z-fighting。正確做法是**重疊關係上的最長鏈**：依層號由低到高處理，高度 = 所有與它重疊且層號更低的面之中最大的高度 + 1。這保證任何一對重疊的面高度嚴格不同。

**三、厚度變化要跟著造成它的那一摺。** 複合摺的子摺各有時間區間，若用整個步驟的進度統一內插，先落下的紙層偏移量還沒到位，就會穿進下方的紙裡。

### 翅膀的展開角度

翅膀若不是接近 90° 展開，兩片會一上一下呈不對稱角度；相機仰角一旦接近其中一片的平面，那片就被壓成一條線，看起來像有東西穿過紙鶴。接近 90° 時兩片對稱，任何仰角都不會有一片被壓扁。

### 主控台診斷

```js
__selftest()  // 一次跑完所有幾何不變量：面積守恆、摺平、同層不重疊、厚度合理
__dump(3)     // 第 4 步結束時各層的攤平多邊形
__probe(3, 1) // 該時刻是否確實攤平（摺平狀態下 y 應全為 0）
```

## 值得記下來的一件事

正方基本型（square base）的教學通常畫成「四個角同時往中間塌陷」的複合動作，那在剛體動畫裡很難乾淨呈現。但**沿兩條中線各對摺一次，數學上就等於正方基本型**：紙的四個角確實都落到同一點，紙的中心成為閉合尖角，四條摺邊與紙層結構完全一致。所以前兩步用單純的對摺就能精確表現，不需要任何近似。
